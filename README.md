# Comparative Evaluation of Convolutional and Transformer-Based
Deep Learning Architectures for Explainable Enamel Caries Stag-
ing from Intraoral Images: A Multi-Seed Study
Multi-seed benchmark of ResNet-50, DenseNet-121, ViT-B/16, and SqueezeNet for explainable enamel caries staging from intraoral images, with Grad-CAM/attention-rollout interpretability and statistical significance testing.
